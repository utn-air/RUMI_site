# RUMI Website

A static research project page following the structure of the TACTIC site. Open `index.html` directly or serve this directory with any static web server.

## Media assets

The overview and hardware illustrations are displayed as responsive PNG images in `static/images/`. Their source vector PDFs are retained in `assets/`.

The original rollout MP4s are retained in `static/videos/`. The page uses muted, looping H.264 versions in `static/videos/web/`, resized to 640 px wide and encoded without audio for lower bandwidth.

The TPV and FPV teleoperation clips and the two haptic teleoperation clips are compressed in the same way and autoplay muted in the page.

The simulated packing scene and real-robot inference setup still have labeled blank media placeholders.
